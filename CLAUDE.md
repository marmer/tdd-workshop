# TDD Workshop

TDD workshop project by Mariano Mertinat. Multi-language (Java, Kotlin, TypeScript) kata base with a Reveal.js presentation.

## Slides

The workshop presentation lives in `docs/index.html` — a single Reveal.js HTML file. Most slide work is wording fixes and content improvements on existing slides.

- Match the language of the text being edited (slides are English, speaker notes are mixed German/English)
- Speaker notes are inside `<aside aria-label="speaker notes" class="notes">` elements
